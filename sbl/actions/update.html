Update data-fsc-action

Updates the quantity of a product already in the cart. Requires a quantity control (a <select> or input) carrying data-fsc-item-path-value and data-fsc-item-quantity-value, paired with a button using the same item path.

AttributeWhereValue
data-fsc-item-path-valuequantity control + button"prod-1" (must match)
data-fsc-item-quantity-valuequantity controlmarks it as the quantity source
data-fsc-actionbutton"Update"
data-fsc-item-quantityany element (optional)mirrors the live quantity for that item path
Note: the product must already be in the cart — add it first, then Update changes its quantity to whatever the paired <select> is set to. The quantity mirror (data-fsc-item-quantity) updates instantly, but open Checkout to confirm FastSpring's own cart reflects the new quantity too.
