Promocode data-fsc-action

Applies a promo code entered by the buyer to the current order. Requires a nearby input carrying data-fsc-promocode-value.

AttributeWhereValue
data-fsc-promocode-valuetext inputholds the code the buyer typed
data-fsc-actionbutton"Promocode"
Note: an invalid code surfaces through data-error-callback rather than throwing — watch the event log below after applying a bogus code.
