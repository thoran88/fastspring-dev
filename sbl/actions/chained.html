Chained data-fsc-action

Combines multiple actions into a single click by comma-separating them in data-fsc-action. They execute left to right — useful for one-click "buy now" buttons.

AttributeWhereValue
data-fsc-actionclickable element"Reset, Add, Checkout" (comma-separated)
data-fsc-item-path-valuesame elementproduct path used by the chained Add
Note: this demo chains Reset → Add → Checkout, so it clears any existing cart contents before adding prod-1 and immediately opening checkout.

Live demo

Source

<button
  data-fsc-item-path-value="prod-1"
  data-fsc-action="Reset, Add, Checkout">
  Reset, add prod-1 & checkout
</button>
