tag fastspring.builder.*
fastspring.builder.tag({'key': 'value'})

Attaches custom order-level tags as key-value pairs. Tags persist through checkout and appear in the resulting webhook payloads — useful for attribution (campaign, affiliate id, internal user id).

Live demo

Source

var key = document.getElementById('tag-key').value;
var value = document.getElementById('tag-value').value;
var payload = {};
payload[key] = value;
fastspring.builder.tag(payload);
