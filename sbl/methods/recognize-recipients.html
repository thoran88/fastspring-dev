recognizeRecipients fastspring.builder.*
fastspring.builder.recognizeRecipients(payload)

Prefills unauthenticated gift-recipient information and enables the gift-purchase flow at checkout — recipient name, address, and an optional gift memo.

Note: like recognize, this adds data to the browser session rather than the builder's own data object.

Live demo

Edit the JSON below, then run — checkout should switch into the gift flow.

Source

var recipient = JSON.parse(document.getElementById('recipient-json').value);
fastspring.builder.recognizeRecipients(recipient);
fastspring.builder.checkout();
