fastspring.builder.add(product, callback?)

Adds a product to the cart without modifying quantity — the JS equivalent of the Add action. Calling it again for a product already in the cart does not increment its quantity.

Note: pass a function as the second argument to run code only after this specific call completes, separate from the page-wide data-data-callback.

  sblLog.note('add() method callback fired');
