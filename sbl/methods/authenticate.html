authenticate fastspring.builder.*
fastspring.builder.authenticate(securePayload, secureKey)

Authenticates a signed payload (account id + timestamp) to redirect an existing customer into their FastSpring account portal.

Note: in real usage, secureKey is an HMAC signature generated server-side from your API credentials — never in browser JS, since that would expose the key that lets anyone authenticate as any account. This demo can only send an unsigned payload, which FastSpring will correctly reject — click Run below to see that rejection come back through data-error-callback rather than succeeding.

Live demo

Source

// secureKey must be generated server-side — this demo omits it, so expect a rejection.
fastspring.builder.authenticate({
  account: document.getElementById('account-id').value,
  timestamp: Date.now()
});
