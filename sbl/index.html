SBL Store Builder Library — Live Actions

SBL Actions & Methods, live

Every data-fsc-action (declarative HTML) and every fastspring.builder.* method (JavaScript) gets its own page, each loading a fresh fastspring-builder.js instance and cart session. That isolation is deliberate — stacking everything on one DOM causes cross-talk (shared session state, click handlers stepping on each other), which is what motivated splitting these out.

Storefront: thoran.test.qa.onfastspring.com/popup-sbl · test products: prod-1, prod-2, prod-3. Every page has a live event log wired to data-data-callback, data-popup-closed, data-popup-webhook-received and data-error-callback so you can see exactly what the builder reports back.
